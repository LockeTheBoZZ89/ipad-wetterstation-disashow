# iPad Air 1 Wetterstation & Diashow (Chemnitz)

Eine elegante, minimalistische Web-Anwendung speziell optimiert für ältere iPads (z. B. iPad Air 1 von 2013 mit iOS 12).

## Features
- **Live-Wetter Chemnitz**: Aktuelle Temperatur, Windgeschwindigkeit und Wetter-Icons (über kostenlose Open-Meteo API).
- **7-Tage-Vorhersage**: Übersichtliche Tagesprognose mit Höchst- und Tiefstwerten.
- **Diashow aus iPad-Speicher**: Eigene Fotos direkt vom iPad laden.
- **Intervall-Einstellung**: Wechselzeit im Einstellungsmenü (⚙️) auf 10, 30 oder 60 Sekunden festlegen.
- **Uhrzeit & Datum**: Große, gut lesbare Zeitanzeige.

## Anleitung für GitHub Pages
1. Dieses Repository clonen oder die `index.html` direkt in dein GitHub-Repository hochladen.
2. Geh in den Repository-Einstellungen zu **Settings -> Pages**.
3. Wähle als Source den Branch **`main`** aus und klicke auf **Save**.
4. Ruf die angezeigte URL auf deinem iPad Safari-Browser auf.
5. Tippe in Safari auf das **Teilen-Symbol** (Viereck mit Pfeil nach oben) und wähle **"Zum Home-Bildschirm"**, um die Anwendung als Vollbild-App zu nutzen.
